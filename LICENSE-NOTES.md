# License notes

The license of CRAFT is not clearly settled. This file records what each
source says. It does not choose one. If you plan to redistribute Craft,
especially commercially, check these sources yourself.

## 1. The original source code (this repository)

The `README` in the 3.5 source archive (kept as
[`doc/README.original`](doc/README.original)) and the original
"Source Code of CRAFT" web page ([`doc/craftcc.html`](doc/craftcc.html))
both say:

> This source code is free, everybody may do everything with it, if it is
> not used commercially. I guarantee absolutely nothing, everything is at
> your own risk and I explicitly warn you not to compile or play the game :-).

The author was Uwe Beyer (uwe.beyer@gmd.de) at GMD.

## 2. Debian

Debian packaged Craft 3.5 from 1999 (packaged by Falk Hueffner, from
`craftcc35.tar.gz`). Its copyright file (craft 3.5-9) says the
copyright belongs to Uwe Beyer and that the game may be redistributed
under the terms of the **Artistic License**.

- https://sources.debian.org/copyright/license/craft/3.5-9

## 3. Wikis and project listings

- **libregamewiki** lists both the code and the media as **GNU General
  Public License**:
  https://libregamewiki.org/CRAFT:_The_Vicious_Vikings
- **SourceForge** (project `craft-vikings`) lists **GPLv2**:
  https://sourceforge.net/projects/craft-vikings/

## Third-party images

Two images from the original web pages were removed from this fork
because their rights are unclear: a scanned cartoon (`ccc.gif`) and a
photo (`pic/hua.gif`). The title-screen picture (`hcraft/m1`, also
`doc/pic/craft.gif`) appears to be a photo of Eilean Donan castle
in Scotland. Where it came from is unknown.
