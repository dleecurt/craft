Source Code of CRAFT

Where to get it

The source code of CRAFT, with its pictures, sounds and these pages, is at https://github.com/dleecurt/craft. Report problems there, under Issues.

How to compile ?

You need a C++ compiler (g++ or clang++), make, the autotools (autoconf and automake), and the X11 and zlib development files. Then: 
git clone https://github.com/dleecurt/craft.git
cd craft
autoreconf -fi
./configure
make
make install      (as root, or ./configure --prefix=$HOME/.local first)
craft can also be started from the directory it was built in, without installing it. The README in the source has the details.
